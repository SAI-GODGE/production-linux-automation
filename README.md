# Production-Ready Linux Server Management & Automation

## Overview

A production-style Linux server management and automation project built on AWS EC2 and Ansible.

The project demonstrates centralized administration, configuration management, security hardening, service deployment, health checks, troubleshooting, and automated reporting across a multi-node RHEL Linux environment.

## Architecture

- 1 Ansible Control Node
- 7 Linux Worker Nodes
- AWS VPC
- RHEL 9
- Ansible
- SSH
- Git

## Objectives

- Automate Linux server configuration
- Standardize server environments
- Implement security hardening
- Manage users and groups
- Configure SSH, firewalld, SELinux and systemd
- Deploy Nginx and Apache
- Implement health checks
- Generate operational reports
- Simulate and troubleshoot production incidents
